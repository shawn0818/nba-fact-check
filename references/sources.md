# 信源分级

## 档位

层级跟着**原始**说话人走，不跟转述方走。同一家 SB Nation，援引了 Shams 的那篇算 insider，纯球迷视角的那篇算聚合。

| 档位 | 是谁 | 能支撑到哪 |
|---|---|---|
| **官方** | 球队、联盟、球员本人（发布会原话、本人账号、官方公告） | 终局事实，可以写"官宣" |
| **联盟级 insider** | 下面名单里的记者，点名报道 | "据 XX 报道"，最高到"已完成（报道）" |
| **跟队记者** | 各队 beat writer 写自己那支队 | 和 insider 同级，但只限本队事务 |
| **在场署名记者** | 媒体日、发布会、赛后采访时到场的署名记者（不一定是跟队记者），以及美联社、路透、法新的现场稿 | 对"这句话是不是这样说的"和跟队记者同级，状态块 `tier` 记 `beat` 并在 `who` 里写明身份 |
| **机构** | 有署名的正规媒体报道，但说不出原始爆料人 | "据 XX（机构）报道" |
| **聚合** | 二次转述、球迷博客、无原始归因的汇总 | 只是线索，必须继续往上追 |
| **内容农场** | 见下文特征 | 不作为任何证据 |

## 联盟级 insider 名单

这张表**由人维护，不让模型判**。让模型评"这个记者靠不靠谱"，它会按名气瞎猜，两次还可能给出不同的答案。表外的记者一律按"机构"处理：说不出是谁爆的，就不假装知道。

| 记者 | 所属 |
|---|---|
| Shams Charania | ESPN（2024 年 10 月由 The Athletic 转入） |
| Adrian Wojnarowski | 原 ESPN，2024 年已退出新闻业，之后不再有新报道 |
| Ramona Shelburne | ESPN |
| Brian Windhorst | ESPN |
| Tim MacMahon | ESPN |
| Bobby Marks | ESPN（工资帽与交易机制分析，不爆料） |
| Dave McMenamin | ESPN（长期跟勒布朗，涉及他的事务时视同跟队记者） |
| Chris Haynes | Prime Video（2026-07 的报道署名；此前为 NBA TV） |
| Marc Stein | 独立（The Stein Line） |
| Jake Fischer | 独立 |
| Michael Scotto | HoopsHype |
| Anthony Slater | ESPN |
| Jovan Buha | The Athletic |
| Sam Amick | The Athletic |

名单会过时：记者换东家时，以报道当时的署名为准。

**专项记者**不在上表，但在自己的领域里同样是首发级信源：例如 The Athletic 的 Andrew Marchand 专跑体育媒体与转播生意，球员和电视台、流媒体的合作（纪录片、解说合同）通常由他首报。按"机构"档记录，在核查小结里写明他的专项。

**注意记者自己加的类比和解读。** Marchand 报道勒布朗与 ESPN 的纪录片时写"类似《最后一舞》"，这个类比是记者的，不是当事人说的；后续的否认针对的正是这个类比。核查时要把"报道的事实"和"报道者的说法"分开。

## 跟队记者

跟队记者写自己那支队时同样权威，但需要"记者 × 球队"的二维表，而且人员流动频繁。核查涉及某支队时，现查该队主要跟队媒体当前的署名（例如费城的 Philadelphia Inquirer、PhillyVoice、The Athletic 费城版），不要依赖记忆里的名字。

## 聚合站：是线索，不是信源

- **ClutchPoints、Sportskeeda、Fadeaway World、Basketball Network、各类 "XX Daily"**：大量二次转述，标题常比正文激进。正文里通常嵌着原始推文或写着 "per XX"，顺着找到第一个人。
- **HoopsHype 传闻页、Hoops Rumors、RealGM wire**：汇总型，但会附原始链接，是很好的**溯源工具**。
- **SB Nation 各队博客**：多为球迷视角；只有援引了原始记者的文章才往上提档。
- **Yahoo Sports 的 NBA feed**：是聚合器。发布者（publisher）字段才是真正的来源，要看它，不要把 Yahoo 当成作者。

## 中文转述者：只是翻译，不是信源

- **虎扑流言板、直播吧、懂球帝、新浪 / 腾讯体育**：主要工作是把英文报道和采访翻成中文。稿件末尾通常写"来源：XX"，这一行是溯源的起点。
- **NBA 中国官网**（china.nba.cn）：同样是转述，但正文里通常直接写明"据 ESPN 记者 XX 报道"，往往一步就能追到英文首发者。
- **百度百科、维基百科**：只能当检索入口，不能作为任何结论的证据，结论里不出现"据百科"。
- 它们写"美媒""据报道""消息人士"时，等于没有给出信源，必须继续往上追。
- 虎扑"[敲钟社·字幕]"之类的字幕视频是翻译作品，核对引语时要回到英文原视频。

## 内容农场的特征

搜索结果里会混进大量内容农场，2026 年 10 月实测时它们拿到的权威度打分和直播吧一样。识别特征：

- 域名是无意义的字母组合或与体育无关（例如 `tjjdpgxh.com`、`nongminsh.com`、`xcskx.net.cn` 这一类）。
- 标题和正文逐字照搬直播吧或虎扑，往往晚几个小时，不注明出处。
- 同一篇文章同时出现在多个这类域名下。
- 挂在明显不相干的机构域名下，例如医院、政府部门的子站发 NBA 新闻（实测见到过 `whszxyy.com.cn` 这种），多半是被挂马或寄生的页面。
- **冒用官方媒体的名义。** 例如自称"CCTV5直播网"的 `cntv-sports.com`，页面上全是赛事直播链接，不是央视官方（央视体育的官方域名在 cctv.com 下）。这类站点会编造细节，实测见到过凭空写出一段"团队解释"。看到"央视""新华"之类的名头，先核对域名。

**查域名注册时间。** 用 `scripts/domain_age.py`（RDAP，WHOIS 的新标准）查。冒名站基本都是新注册的，2026-10-18 实测：

| 域名 | 注册时间 |
|---|---|
| cntv-sports.com（自称"CCTV5直播网"） | 2025-07-18 |
| vip-sports-cctv.com（冒用央视名义） | 2025-10-15 |
| zhibo8.com（直播吧） | 2007-05-18 |

注册时间只是信号，不是结论：新站也可能是正规媒体的新域名，老站也可能内容很差。

处理方式：只把它们当作"这件事可能存在"的提示，回到原始的中文转述者或英文出处去核对，不作为任何证据引用。

## 假冒与讽刺账号

NBA 圈的社媒上有大量冒充记者的账号和讽刺账号，它们的内容经常被中文转述成"名记：……""美媒爆料"。

| 类型 | 特征 | 怎么查 |
|---|---|---|
| **讽刺号** | 例如 NBA Centel：专门发以假乱真的"突发新闻"，简介里写明 satire 或 parody | 看账号简介；搜这条"新闻"有没有正规媒体跟进，没有就基本可以确定是段子 |
| **仿冒记者号** | 在真名里加一个字母、换一个相近字符（例如 Shams 的名字多一个 a），头像和简介照抄真号，粉丝数远少于真号 | 逐字母核对账号名；对照真号的粉丝量和注册时间；看真号那天有没有发同样的内容 |
| **伪造截图** | 推文、IG 截图是 P 出来的，"Woj bomb"式的假爆料截图最常见 | 截图不是证据：找原帖本身，或可靠媒体对原帖的引用；真号当天的时间线里没有这条，就按查无出处处理 |
| **"内部人士"号** | 自称有内部消息、从不给出处，偶尔说中一次就被反复引用 | 不进 insider 名单；它们的说法一律按"查无出处"处理，直到有具名记者或官方证实 |

本 skill 的检索工具进不了 X 和 Instagram，所以这一步往往要通过媒体报道间接完成：正规媒体引用过的帖子，通常会写明账号；只有中文自媒体在传、没有任何英文媒体引用的"推文"，要高度怀疑。

## 当事人方面的信源

- **球员本人**：发布会原话、本人社媒原帖。本人宣布 = 官方。
- **经纪人**（例如勒布朗的经纪人 Rich Paul / Klutch Sports）：经纪人的公开表态是一手信源，但代表的是谈判立场，不等于事实已成。
- **商业伙伴**（例如勒布朗的长期商业伙伴 Maverick Carter）：他在社媒上的表态、加上本人转发，可以视为当事人一方的正式说法。但要逐字看他否认的到底是什么：2026-07-30 Carter 否认的是"《最后一舞》式告别片"这个定位，被一路转述成了"否认拍纪录片"。
- **本人否认**：记为"本人辟谣"状态，不能单独当作"已证伪"的依据。
