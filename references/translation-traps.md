# 翻译陷阱

总原则：**中文的确定性不得强过英文，也不得无故弱于英文。** 译得比原文满是错的；把原文确定的事实译成"据称""或许"，同样是走样。英文没写的状态，中文里不许长出来；英文写死了的，中文也不要无根据地软化。

## 一、交易、签约、去留

| 英文 | 实际意思 | 常见误译 |
|---|---|---|
| has interest / is monitoring | 有兴趣、在关注 | "想要""追求" |
| open to | 愿意考虑 | "希望""寻求" |
| exploring / has had discussions | 在试探、聊过 | "正在谈判" |
| in talks / negotiating | 正在谈判 | "即将达成" |
| frontrunner / a real possibility | 可能性较大 | "确定""将" |
| expected to / nearing / intends to | 预期、接近、打算 | "将""已" |
| plans to | 计划 | "将会"（计划会变） |
| agreed to terms / reached agreement | 口头达成，尚未签字、尚未官宣 | "已签约" |
| signs / has signed（记者报道） | 已签，但消息来自记者 | "官宣" |
| officially / the team announced | 官宣 | — |
| I'm told / per sources / sources say | 匿名消息源 | 被直接写成事实陈述 |

**弱化词管辖它后面的动词。** `expected to sign` 里的 `sign` 不是断言，它在 `expected to` 的范围里，整句的强度只看弱化词。中文写成"签约 76人（有望）"之类，把动词提到前面，读起来就成了已完成。

## 二、伤病与出战状态

NBA 官方伤病报告的状态词有固定含义：

| 官方状态 | 意思 | 常见误译 |
|---|---|---|
| Available | 可以出战 | — |
| Probable | 很可能出战 | "确定出战" |
| Questionable | 出战成疑，不确定 | "大概率缺阵""将缺阵" |
| Doubtful | 不太可能出战 | "确定缺阵" |
| Out | 缺阵 | — |

其他高发误读：

- **game-time decision (GTD)**：赛前才决定，不代表倾向任何一边。
- **day-to-day**：每天评估，通常是轻伤，不等于"缺阵数日"。
- **will be re-evaluated in two weeks**：两周后复查，**不是**"缺阵两周"。复查后可能还要继续缺阵。
- **out indefinitely**：无限期缺阵，没有给出时间表，不能被译成任何具体时长。
- **rest / injury management / load management**：轮休或伤病管理，和真实伤病是两回事，不要译成"受伤"。
- **"(Injury) – Left Knee; Soreness"**：报告里的伤病描述只写部位和症状，不要自行补出诊断（例如把 soreness 写成"拉伤"）。

## 三、合同与金额

| 英文 | 实际意思 | 注意 |
|---|---|---|
| veteran minimum | 老将底薪 | 金额随球龄和赛季变化；中文的"底薪 388 万"要核对币种（美元）和年份 |
| player option / team option | 球员选项 / 球队选项 | 两者方向相反，最后一年是谁说了算完全不同 |
| fully / partially guaranteed | 全额 / 部分保障 | 不能省略 |
| extension | 续约（在现有合同基础上延长） | 不等于新签 |
| up to $X / with incentives | 最多 X、含激励条款 | 不能写成"X" |
| two-year deal | 两年合同 | 如果含选项，"两年"的第二年可能并不确定 |

合同金额多数由记者报道，球队一般不公布。所以金额类说法最高只能到"据 XX 报道"。

**币种和单位最容易漂。** 中文稿里的"388 万""2000 万"几乎都是美元，但常常不写币种，二次转述时就可能被当成人民币，或者和人民币数字放在一起比较。数字类核查点要写明币种；英文原文写的是 "$3.9 million"，中文写"390 万"可以，写"390 万元"就是错的。

## 四、数据与纪录

| 英文 | 实际意思 | 常见误译 |
|---|---|---|
| first player ever to | 史上首位 | — |
| first since 1990 / first in X years | 自某年以来首位 | "史上首位" |
| in NBA history / in franchise history | 联盟历史 / 队史 | 两者混用 |
| regular season / including playoffs | 常规赛 / 含季后赛 | 省略口径 |
| oldest to | 史上最年长的…… | 年龄要按比赛当天算 |
| per StatMuse / per Elias | 数据来自 StatMuse / Elias | StatMuse 是数据工具，不是官方纪录 |
| ties / passes | 追平 / 超越 | "超越"写成"追平"或反过来 |
| career-high / season-high | 生涯最高 / 赛季最高 | 两者混用 |
| led the team / team-high | 全队最高（**可能并列**） | 写成"独占全队最高"；或只比主力、漏掉替补里的并列者 |

## 五、引语

- **原话的场合要一起交代。** 发布会回答的是哪个问题、是不是玩笑或反讽、是不是在复述别人的说法。
- **"他说"和"他暗示"不同。** 记者对原话的解读（"LeBron hinted at …"）不能翻成他本人的原话。
- **转述引语和直接引语。** 英文报道里没加引号的部分是记者的转述，中文不能加上引号变成直接引语。
- **翻译过的引语再回译，会漂移得更远。** 核对引语时一定要回到原始英文，最好是原视频或官方实录。
- **对谈里先确认每句是谁说的。** YouTube 自动字幕用 `>>` 标记换人，但不标是谁，而且标记本身会漏、会错，不能靠它数轮次。转述稿常把几轮对话合并成"他说"，附和者插的话就可能被安到主角头上。判断方法见 `primary-sources.md` 的"说话人归属"；判断不了时写明"归属存疑"并给出视频时间点。
- **查不到出处的引语，结论要写得准确。** 不写"他从未说过"（我们证明不了一件事没发生），写"他本人的发言记录和媒体报道里都找不到这句话"，并列出搜过哪里。中文圈流传的"詹姆斯语录"很多属于这一类。
- **旧话翻新**：先用引语关键词配 `before:` 往前搜，确认第一次出现的日期和场合，再判断是不是被当成了新表态。
- **原话没有宾语时，不要替它补。** "wasn't good"没说是什么不好，译成"那段广告拍得并不好"就是替说话人做了解读。
- **will 不等于 must。** "you will always respect me" 是"你们总会尊重我"——自信；译成"你们必须尊重我"就成了索要，读者对说话人的印象完全不同。先读完整上下文定读法，判法见 `judging.md` 第三节的"原话的语气本身有歧义时"；偏强的译法改变了读者对说话人态度的判断，就是措辞放大。
- **俚语和代称**：例如 "the Stripes" 指阿迪达斯（三道杠），"the Swoosh" 指耐克。

## 六、中文一侧常见的放大写法

| 写法 | 问题 |
|---|---|
| "美媒称""外媒曝" | 没有指向任何具体信源，必须追到具体媒体和记者 |
| "官宣" | 只有球队、联盟、本人宣布才能用 |
| "曝""据悉" | 匿名或二手，等于"据报道"，不是事实陈述 |
| "将""已" | 对照英文原文的情态，多数时候英文只到"有望" |
| "炮轰""怒怼""回击" | 情绪化动词常常强过原话的语气，要回原话核对 |
| "史上第一人" | 先确认口径，多数情况下是"自某年以来"或"队史" |
| "被调查""调查风波" | 先确认调查主体：记者 looking into ≠ 联盟 investigating ≠ 执法机构 |

## 七、中文转述的六种走样（2026-10-18 中文复盘实测）

用新闻库里的几条历史传闻，逐条对照当时的中文稿和英文原文，归纳出下面六种。前四种出现在标题里，后两种藏在正文里，所以**正文要逐句核，不能只核标题**。

| 走样 | 例子（英文原意 → 中文写法） | 怎么查 |
|---|---|---|
| **推断写成事实** | 热火在招 YouTube 总监（启事两周前就挂了）→"因误发视频解雇涉事员工，次日招人替代" | 找到推断所依据的那个事实，核它的时间顺序；"因为……所以……"的因果是谁说的 |
| **归因上移** | 商业伙伴 Carter 发文、勒布朗转发 →"詹姆斯：不会制作《最后一舞》式纪录片""詹姆斯亲自辟谣" | 核"谁说的"：转发 ≠ 本人说，经纪人、伙伴 ≠ 本人 |
| **否认对象扩大** | 否认"告别片"定位 →"没有拍摄个人纪录片计划" | 逐字看否认的宾语 |
| **情态拔高** | negotiating buyout, intends to sign →"买断后加盟76人！詹姆斯等来最强帮手" | 对照断言强度阶梯 |
| **引语重写** | "I don't want to speak into the future right now…It won't be another year plus 24" →「詹姆斯：不保证两年800万合同到期就退役」 | 中文里加了引号的"原话"，一律回英文原话核对；方向都可能被写反 |
| **附加无源句** | 15% 交易保证金属实，但同一篇还加了一句"詹姆斯已公开表态不会跳出合同"，查不到出处 | 正文每一句事实陈述都要能对应到出处；对应不上的单列为"查无出处" |

**中文稿的可靠程度不是按"大小"排的。** 这次复盘里：

- 虎扑流言板、直播吧、NBA 中国官网，标题里通常写明记者名字（"Chris Haynes：……""商业伙伴称……老詹转发"），基本准确；
- 懂球帝有时把归因往上移；
- **体坛周报**这样的老牌媒体也会把推断写成事实，而且被极目新闻、上游新闻等正规媒体原样转载；
- 内容农场写的反而可能是对的（"1 年 390 万底薪""15% 交易保证金"都属实），但它们**说对了也不能当证据**，要回到上游核实。

判断一篇中文稿，看的是它有没有交代信源、有没有把推断和事实分开，而不是看它是哪家媒体。

## 八、高频陷阱（完整清单）

SKILL.md 只列了最常见的几条，这里是全部。

- 把"美媒""据报道""消息人士"当成信源。它们只是转述的标记，不指向任何人。
- **把仿冒号、讽刺号当成记者。** NBA Centel 这类讽刺号、在记者名字里多加一个字母的仿冒号、P 出来的推文截图，被中文转述成"名记："。先核对账号本身。
- **时区没统一就比先后。** 北京时间比美东早 12 到 13 小时，同一条消息的中文稿日期常常晚一天，别据此误判谁先谁后。
- **只核利空、放过利好。** 吹捧的说法同样可能是假的。
- **"调查"的主语被偷换。** "某某被调查"先问是谁在调查：记者在查、联盟在查、执法机构在查，分量天差地别。中文标题常把记者的"looking into"写成"调查风波"，读者自然理解成联盟立案。
- **引语后面那句限定被删掉。** 说话人自己紧接着补的一句"不过也可能不是这样"，在转述里消失了，整段话的意思就反过来了。核对引语时要读到原话的下一句。
- **把两个人的话拼成一个人的。** 播客和对谈里，主持人复述、附和一句很常见，转述稿容易把几轮对话合并成一段"他说"。
- **否认的是说法，不是事件。** 当事人否认的常常只是报道里的某个定位或类比，转述一路传下去，就变成了否认整件事。复盘案例：勒布朗的商业伙伴否认"《最后一舞》式告别片"，到中文站成了"没有拍摄纪录片计划"。逐字看否认的宾语是什么。
- **记者的类比被当成事实。** "类似《最后一舞》""下一个某某"这类说法，多半是报道者自己加的，不是当事人说的。
- **预备素材被当成信号。** 球队会为"可能发生"的签约提前准备视频、海报，误公开后常被解读成泄露。复盘案例：热火误公开"入队发布会"视频，当天就被官方澄清。
- 把十篇转载当十个信源。
- 把记者报道的"已签约"当官宣。
- 伤病状态词按字面理解：questionable 不是"大概率缺阵"，"两周后复查"不是"缺阵两周"。
- 数据口径混用：常规赛和季后赛、"史上首位"和"自 1990 年以来首位"、联盟纪录和队史纪录。
- 年龄类纪录按错了日期：要按比赛当天的年龄算，不是按赛季或按今天。
- 引语脱离场合：玩笑、反讽、回答别的问题时说的话被单独截出来。
- 拿 Basketball-Reference 或维基百科的二手整理，当作对一段言论或一次交易的终局证据。
- 搜索结果里内容农场的打分可能和正规媒体一样高，不能拿打分代替判断。
- 把"搜不到"写成"假的"。
